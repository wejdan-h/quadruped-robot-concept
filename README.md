# Quadruped Robot Concept

A conceptual mechanical design of a quadruped robot developed using Autodesk Fusion 360.

## Overview

This repository contains the initial mechanical concept of a four-legged robot. The project focuses on the structural design of the chassis, leg configuration, joint layout, and basic mechanical considerations required for a stable quadruped platform.

## Features

- Rectangular chassis with rounded edges
- Four-leg mechanical structure
- Hip and knee joint concept
- Front display area
- Preliminary mechanical design
- Fusion 360 CAD model
- Engineering documentation

## Software

- Autodesk Fusion 360
